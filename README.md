# 🌿 Plant Disease Prediction

A deep learning-based web application that detects plant diseases from leaf images using a Convolutional Neural Network (CNN).

The model is trained on the PlantVillage dataset and deployed using Streamlit.

---

## 🚀 Demo

🔗 Live Demo: https://plantdiseaseprediction-wssarvqwvskufongzrxsg8.streamlit.app/

---

## 📌 Features

- Upload plant leaf images
- Predict plant diseases instantly
- CNN-based image classification
- Confidence score prediction
- Simple and interactive Streamlit UI

---

## 🧠 Model Information

- Framework: TensorFlow / Keras
- Architecture: Convolutional Neural Network (CNN)
- Dataset: PlantVillage Dataset
- Input Image Size: 224 × 224

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/mayaannkkk/Plant_Disease_Prediction.git
```

### 2️⃣ Move to Project Directory

```bash
cd Plant_Disease_Prediction
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the Application

```bash
streamlit run main.py
```
